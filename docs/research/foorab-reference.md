# Research: foorab theme (owner's reference for everyday usage)

Source: https://www.esnpc.com/foorab-for-foobar2000-theme/ (v2.25.10). The owner's older copy
of this Chinese build (foobar2000 2.0 x86, Asion localization) is what they use daily.

Useful ideas for Glasswave, mapped to WMP 12 / WMC equivalents:

- Sidebar playlists including smart lists: library, history, most played, recently added,
  favorites, by rating (needs playback statistics, e.g. foo_playcount).
- Library tree browsing (folder / artist / album), cover gallery with smooth scrolling.
- Big now-playing panel with cover, title/artist/album, ratings; lyrics via ESLyric.
- Columns: cover, status, #, title, artist, album, favorite, rating, play count, bitrate, time.
- Mini window; popup playlist manager (Tab / middle-click).
- Status bar with codec, bitrate, sample rate, channels, position.
- Bundled components worth considering: cuefixer (hides cue/image duplicates — Glasswave has
  its own source-identity dedupe), ESLyric, playback statistics, spectrum analyzer.

Not adopted: GDI/D2D script rendering, MicaForEveryone (system-wide), JS panels.
